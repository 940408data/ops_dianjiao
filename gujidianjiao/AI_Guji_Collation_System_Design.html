卷一问题的本质

古籍校勘的难点，从来不是「把字认出来」。真正的难点有三个，任何一个做错， 产出的本子就是废本甚至是有害的本子。

难点一：不是所有「不同」都是异文

底本作「逺」而今本作「远」，这不是异文，是字形；底本作「說」而今本作「悦」， 这不是讹误，是通假；底本作「人」而今本作「民」，这不是版本优劣，是避讳—— 而且这个「人」字恰恰是判定底本时代的硬证据，一旦被「改正」，版本信息就永久损毁了。 一个只会做字符串 diff 的系统，会把这三类混为一谈，产出一张几千条的噪音清单， 比不校还糟。

难点二：AI 最容易犯的错，正是校勘学最忌讳的错

语言模型的本能是让文本「读起来通顺」。而清代校勘学最严厉的告诫恰恰是 「凡无左证而以意改者，虽通亦不可从」。理校（凭文义推断）在四种校法中风险最高， 段玉裁、王念孙都极为慎用，而这正是 LLM 不加约束时最擅长、也最容易滥用的一种。 所以系统设计的核心不是「让模型更聪明」，而是限制模型在何种证据下才被允许动底本一个字。

难点三：底本可以公开，参校本不可以

公有领域善本的文字不受著作权保护，可以自由传播。但现代点校本的 标点、分段、校勘记是整理者的独创性成果，受法律保护。 若系统把现代本的标点直接搬到公开本上，产出的就是一个侵权文件—— 而且这种侵权极其隐蔽，因为正文一个字都没抄。

三条不可让步的约束。整套系统的每个模块，都是为了守住这三条：
① 底本可通则不改。没有确证或旁证而想动底本正文的，一律悬置，不允许「文义较顺」改字。
② 公开本的句读必须独立生成。现代本的标点只作为提示参与比对，绝不直接落盘。
③ 宁可标记不确定，不可自作主张。OCR 遇漫漶输出「□」而非猜字；合议无共识就「两存」。

卷三S0　底本遴选与权属隔离

底本的选择标准

底本不选「最好读的本子」，选最接近祖本、且可公开的本子。优先级： 唐写本残卷 ＞ 宋元刻本 ＞ 明清精刻本 ＞ 影印本。同时必须核实两层权属：

层次对象状态系统处理
文字层古籍原文公有领域可公开、可改编、可商用
影像层馆藏扫描件视机构条款而定须逐馆确认；部分馆对影像另设限制，系统只存哈希与引用，不再分发原图
整理层现代点校本的标点／分段／校记受著作权保护派生物只落 internal/，强制加不可传播声明
权属熔断 配置中底本 rights 若非 public-domain，系统自动置 publish_public_edition = false，本次运行不产出任何公开文件。 这条是硬熔断，不依赖使用者自觉。

版权隔离的三重措施

  1. 物理隔离。目录分为 public/ 与 internal/， 现代本的任何派生物不进入前者。
  2. 句读独立。公开本的标点由独立断句器生成，现代本标点只用于比对统计， 不写入公开本（详见卷八）。
  3. 表达与事实分离。校勘记只记录「某本作某字」这一事实， 不复制他人按语的措辞。按语由智能体依据证据重新撰写。

卷四S1　OCR 与视觉复核

古籍 OCR 与通用 OCR 的根本差别：错误不是随机的，是结构化的。 知道错误的分布，才谈得上防御。

错误源典型表现防御手段
形近混识省／眚、己／已／巳、傳／傅易混字组表 → 强制降置信 → 回原图复核
重文号「々」被展开成具体字，或被吞掉重文号单列符号集；展开痕迹归入「衍文重出」类
虫蛀漫漶模型「脑补」出一个合理的字硬规则：辨认不出必须输出 □，不许猜
夹注串行双行小字注被读入正文版面分析先分层，layer 标记 main／interlinear
避讳缺笔缺末笔被识别为另一个字视觉复核提示词显式要求区分「缺笔避讳」与「讹字」

置信度融合

OCR 通道甲、通道乙、视觉复核三方是相对独立的证据源，按对数几率相加合成后验：

ℓ = Σi ln[ pi / (1 − pi) ]　，　 p = σ(ℓ) = 1 / (1 + e−ℓ) 互相印证时置信度上升（0.80 ⊕ 0.80 → 0.94），互相矛盾时迅速塌陷 （0.05 ⊕ 0.90 → 0.32）。后者正是「漫漶字被复核确认为漫漶」的情形， 低置信会一路传导到裁决层，强制触发悬置。

每个字都保留 bbox。没有 bbox 就无法回原图定位，视觉复核和人工核验都成了空话—— 这是整个流水线里最容易被省略、也最不能省略的一项。

卷五S2　字形规范化（CNF 中间层）

把两侧文本投影到同一个「校勘中间层」，让不该算异文的差异在此消解， 该算异文的差异在此保留。这一步做错，后面全是噪音。

差异类型示例CNF 中理由
简繁学／學消解同一个字的不同书写系统
异体俗字逺／遠、汎／泛消解刻工书写习惯，非文本差异
通假古今字說／悅、弟／悌保留反映用字时代，须出校记
避讳改字人／民、玄／元保留版本断代的关键证据
形近讹误省／眚保留可能是刻误，也可能是 OCR 误

规范化必须可逆索引：CNF 的每个字符都记录其在原文中的下标， 校勘结论最终要落回底本原字形。绝不能把底本「洗成」现代字——那样产出的 就不是点校本，而是一个假的善本。

卷六S3　对齐与异文检测

两级对齐

一级：锚点对齐。以长公共子串为锚，把长文切成互相对应的段块。 万字以上文本若做单次全局比对，远处的相同字会被错配，产出大量幻影异文。

二级：字符级对齐。段块内用带古籍代价函数的 Needleman–Wunsch。 代价函数是这一层的灵魂——它把校勘学的先验知识编码进了距离度量：

d(a,b) = 0　（CNF 相同：简繁、异体）
d(a,b) = 0.25　（通假或古今字）　　 d(a,b) = 0.35　（避讳改字）
d(a,b) = 0.45　（形近易混，疑 OCR 误）　　 d(a,b) = 1.00　（其他）
空位代价 g = 0.80 因为 d形近 < g，形近字会被判为「一处替换」而非 「一脱一衍」，符合校勘直觉。反之当 2g < 2d 时（如「文學 ↔ 學文」）， 算法会输出「删—同—补」的形态，这不是错误而是代价函数的必然结果， 故设一道形态归并把它还原为一条倒文。

九类异文

字形差异（自动消解，不入校记）、通假古今字、避讳改字、形近疑误、脱文缺字、 衍文重出、倒文、句读、实质异文。分类结果决定了后续由谁主审、权重多少—— 这是分型加权的输入。

切条规则

相邻差异先合并成跨度，再按下列规则拆条，因为校勘记以字为单位：

  • 等长且互为易位 → 整跨度作一条倒文
  • 等长非易位 → 逐字拆条（「弟謹 ↔ 悌敬」须拆成通假、实质异文两条）
  • 不等长 → 整跨度作一条（脱／衍／实质异文）

卷七S4　校书官合议庭

设计的要点不是「让模型扮演古人说话」，而是把陈垣《校勘学释例》的校法四则 拆成互相制衡的角色，每个角色只被允许使用自己那一路证据。

为什么要限权？如果让一个模型同时掌握四种校法，它会自然滑向理校—— 因为「文义顺畅」是语言模型最容易计算的信号，而版本实证、他书引文是它最难核实的。 不限权的结果必然是理校泛滥。角色隔离 ＋ 分型权重，是对这一风险的工程化约束。
劉向
對校法 · 西漢 · 領校中秘書

只比版本异同，只据版本形态立论：行款、字数、避讳、刻工、篇第、重文号。

铁律：不改一字。不得以「文义较顺」为据主张改字。 晚出之本经人整理，往往反失其真。

解縉
他校法 · 明 · 永樂大典總裁

只用本书以外的证据：类书所引、古注所引、碑版石经、写本残卷。

铁律：引证必须指名出处，不能确指即须声明「未得确证」。 伪造书证是校勘之罪，甚于不校。

戴震
本校法・理校法 · 清 · 皖派樸學

用本书内部文例与小学训诂立论；通假须合乎古音声纽韵部，不得仅因今音相近。

铁律：主张改字时必须同时申明「若不改，于文义有何窒碍」。 二字皆可通则存异不改。

紀昀
總纂・裁斷 · 清 · 四庫全書總纂官

不亲校一字，只做终审，且不得引入三家未提出的新证据。 裁断准则按证据等级：底本可通 ＞ 版本实证 ＞ 他书确证 ＞ 本书文例 ＞ 音韵通转 ＞ 文义顺适。

铁律：三家分歧而无一方有硬证据者，必须判为「两存」。 悬置不是失职，妄断才是。

三家互不相见地独立发议——这是刻意的。若让他们看到彼此的意见， 模型会迅速趋同（附和效应），合议就退化成一个人的意见被复述三遍，加权投票也就失去意义。

卷八S5　裁断与悬置

聚合不是简单多数。校勘学里证据是分等级的：一条唐写本的实证，胜过三条「文义较顺」的推测。 故采用双因子加权：

S(h) = Σk wk(t) · gk · ck,h 　，　 P(h) = S(h) / Σh′ S(h′) wk(t)：角色 k 在异文类型 t 上的话语权（见上表）
gk：本次发言的证据等级系数——确证 1.00｜旁证 0.70｜推测 0.40｜无证 0.15
ck,h：角色 k 对读法 h 的置信度

底本优先偏置

若 h 即底本原文，得分再乘以 (1 + β)，β = 0.15。这一项把清儒 「底本可通则不改」的成规直接写进了目标函数——不是靠提示词劝说模型克制， 而是让保守选项在数学上就占优。

三条悬置规则

规则一 · 票数不足 P(1) < τ　（τ = 0.55）——首选读法未获过半支持。
规则二 · 差距过小 P(1) − P(2) < δ　（δ = 0.18）——首选与次选难分伯仲。
规则三 · 无证改字（最要紧） 拟改动底本正文，而三家最高证据等级仅止于「推测」——没有硬证据就要动底本的，一律悬置。 此外，底本该处 OCR 置信度低于 0.75 的，无论合议多么一致，也一律悬置回原图核验。

悬置项绝不改动正文，只在校勘记中「两存之，俟考」。 系统的成功指标不是「自动决议率越高越好」，而是该悬置的都悬置了。

卷九S6　双本产出与独立句读

公开本的句读为什么必须独立生成

底本文字是公有领域，但现代点校本的标点是整理者的独创性成果。直接把现代本的标点 投影到底本上，正文一字未抄，产出的却是一个侵权文件。故系统的做法是：

  1. 用独立断句器（语气词收句、引语动词起引号、发语词前顿开）生成初稿， 刻意不参考现代本；
  2. 现代本标点只用于比对统计，产生「句读分歧」条目送合议庭；
  3. 计算两者句读位置的 Jaccard 重合率，超过 0.92 即告警并要求人工重新断句， 防止「洗稿式抄标点」。

断句器刻意保守：「而」「則」不触发顿开，因为现代各家在此处的取舍差异极大， 跟着它走就等于抄它的判断。「也」「與」按位置定性而非按词性猜测，宁可漏断不可错断—— 漏断只是不够精细，错断是硬伤。

卷十S7　人工精校与回灌

人工的价值稀缺，所以人工只做机器不敢定的事。审校台的设计目标只有一个： 每条悬置项能在 15 秒内做完决定。

  • 默认只显示悬置条目，机器已定的折叠在「已决」页签；
  • 每条完整呈现：上下文、底本读法、今本读法、三家原始意见与证据等级、机器裁断与悬置原因；
  • 候选读法一律投影为正体——否则人工会不小心选出一个简体字落进公开本；
  • 键盘流：J/K 移动、1–9 选读法、3 两存、E 导出；
  • 决策存于本机，导出 decisions.json 回灌流水线，重出定本，人工按语并入校勘记。

单文件、零依赖、可离线打开。校勘工作常在无网络的善本阅览室进行，这不是技术洁癖。

三个典型判例

判例一　避讳「人／民」——机器没有上当

底本「使人以時」，今本作「使民以时」。系统识出这是唐讳（太宗李世民）改字， 刘向以确证主张存底本之旧：「此避讳改字之迹，正可据以定版本时代，不可回改」； 解缙引《经典释文》主张作「民」。加权后底本读法胜出，正文不改，出校记著其本字。 若换成朴素的「以今本为准」策略，这里就会丢掉一条断代证据。

判例二　形近「傅／傳」——机器承认自己不知道

底本 OCR 作「傅不習乎」，今本作「传不习乎」。戴震的判断是 「二字形近而皆可成文，非训诂所能决。当覆核书影字口，不可以意定之」—— 三家俱主两存，且该字 OCR 置信度仅 0.67，双重触发悬置。人工核验书影后判「右旁从叀不从尃」， 定为 OCR 误识而非版本异文。这是系统最该有的行为：不装懂。

判例三　倒文「文學／學文」——他校证据一锤定音

底本作「則以文學」，今本作「则以学文」。刘向无版本可据，只能「姑仍底本之旧」； 戴震以文义推测今本较顺，但自陈「无左证而以意乙正，不可从」； 解缙检得《后汉书》李贤注引作「則以學文」，属确证，权重压倒性胜出，据改并出校记。 这正是他校法的价值所在，也说明引文索引库的质量直接决定系统上限。

卷十二验收指标与工程路线

该看什么指标

不要用「自动决议率」当 KPI——把 τ 调低就能刷到 99%，代价是把该问人的都替人答了。 真正该守的是下面三个：

指标定义目标性质
误改率被自动改动、经人工判定为错误的字数 ／ 总字数< 0.02%一票否决
异文召回金标准异文中被检出的比例> 98%漏检比误报更危险
假异文率字形差异被误报为异文的比例< 1%决定人工是否被噪音淹没
悬置精度悬置项中人工确实推翻机器首选的比例> 30%过低说明悬置太滥
句读独立度与参校本句读的 Jaccard 距离< 0.92合规红线
人工工时每万字所需人工分钟数基线的 1/5 以下项目存在的理由

三期实施

  1. 一期 · 打通（1–2 月）。选一部万字内、且已有可靠点校本的书作靶子， 先建金标准异文集，把误改率与召回率的度量做扎实。此期的目标不是产出成果，是建立度量。
  2. 二期 · 提质（3–5 月）。接入真实古籍 OCR 与多模态复核； 建类书／古注引文索引库（这是他校法的弹药，也是投入产出比最高的一项）； 用一期的金标准做 A/B，校准 τ、δ、β 与分型权重。
  3. 三期 · 规模化（6 月起）。按卷分片并发；引文库转向量检索； 建校勘知识库沉淀已决判例，同类异文可复用；人工审校台接多人协作与仲裁。

规模化的三个技术要点

  • 分片必须按篇章而非按字数。跨篇章切分会破坏锚点对齐，产生大量幻影异文。
  • 合议要做缓存。同一部书中「說／悅」会重复出现数十次， 按 (异文类型, 底本字, 今本字, 上下文指纹) 缓存判例，可省去绝大部分模型调用。
  • 审计记录必须全量留存。每条结论的三家原始意见、证据等级、 得分明细都要可回溯。校勘结论是要被同行质疑的，答不出「凭什么」就没有学术价值。
